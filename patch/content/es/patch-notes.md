### 1.1.3

Con este parche hacemos una pequeña revisión de las habilidades disponibles para facilitar la personalización de los equipamientos y simplificar el equilibrado futuro.
Se desactivan los elementos sin uso o difíciles de equilibrar, y se cambian las variantes de habilidad para que la habilidad estándar sea la más popular de las variantes antiguas.
En los casos en los que nadie usaba las variantes alternativas, solo queda disponible una versión de la habilidad.
Si hay suficiente demanda o tiene sentido para el equilibrio, estos elementos pueden volver y volverán.

* Desactivada la visión templaria.
* Desactivada la precisión adicional.
* Desactivada la huida rápida.
* Disfraz: la base es recarga rápida, una alternativa: larga duración
* Impulso de carrera: la base es rápido, dos alternativas: larga duración, recarga rápida
* Humo: la base es larga duración, una alternativa: potente
* Pistola: la base es disparo rápido
* Petardos: la base es recarga rápida, una alternativa: potente
* Transformación: la base es potente, una alternativa: recarga rápida
* Cuchillos: la base es larga duración
* Embestida: la base es ahora poca velocidad, poco alcance, poco alcance
* Señuelo: la base es recarga rápida
* Silenciador: la base es larga duración, dos alternativas: potente, recarga rápida
* Veneno: la base es acción lenta

Otros cambios:

* Reintroducido Se Busca con objetivos aleatorios, objetivos por venganza y herencia de objetivos.
